# 深圳小学升初中 · 错题分析与训练系统

> 专为深圳六年级小学生升初中备考设计，涵盖知识点全集、易错题练习、模拟试卷与错题分析。

---

## 快速开始

无需安装任何依赖，直接用浏览器打开即可：

```bash
open index.html
```

或在 Finder 中双击 `index.html`。

---

## 功能模块

| 模块 | 说明 |
|------|------|
| 🏠 **主页** | 学习进度总览，快速访问各功能模块 |
| 📖 **知识点全集** | 按科目和章节分类的核心知识点，含公式、⚠️ 易错提示和例题 |
| ✏️ **易错题练习** | 30+ 道精选易错题，选择/填空/判断，答后即时解析 |
| 📝 **模拟试卷** | 数学、语文、英语三套完整试卷，限时作答，自动批改评分 |
| 📕 **错题本** | 自动汇总答错题目，按科目筛选，可标记"已掌握" |
| 📊 **学习报告** | 各科正确率统计，薄弱章节分析 |

## 知识点覆盖（人教版六年级）

### 📐 数学
- 整数与小数的四则运算、运算律
- **分数与百分数**（÷分数=×倒数、折扣陷阱）
- 比与比例（正反比例、比例尺）
- 平面/立体几何（面积、体积、组合图形）
- 统计与概率（平均数 vs 中位数）
- 简单方程（移项变号）

### 📝 语文
- 汉字与拼音（多音字、形近字、声调）
- 词语积累（成语误用、近义词辨析）
- 句子语法（病句类型、修辞手法、的/地/得）
- 古诗词（六年级必背篇目、作者朝代）
- 阅读理解（记叙文/说明文答题技巧）

### 🔤 英语
- 词汇（不规则动词过去式、名词复数、比较级）
- 语法（冠词 a/an/the、四种基本时态、可数与不可数名词）
- 句型转换（一般疑问句、特殊疑问句）

## 项目结构

```
exam-prep/
├── index.html              # 应用入口
├── css/
│   └── style.css           # 深色主题设计系统
├── data/
│   ├── knowledge.js        # 知识点数据
│   ├── questions.js        # 易错题题库
│   └── exams.js            # 模拟试卷数据
└── js/
    └── app.js              # SPA 路由与全部交互逻辑
```

---

## 数据说明

- **知识点**：覆盖数学 6 章、语文 5 章、英语 3 章
- **题目**：30+ 道精选易错题，每题含详细解析
- **试卷**：3 套完整模拟卷（数学 120 分/语文 120 分/英语 100 分）

---

## 技术栈

- **纯前端**：HTML + Vanilla CSS + JavaScript，无需任何框架或构建工具
- **数据持久化**：`localStorage`，刷新页面进度不丢失
- **字体**：Google Fonts（Noto Sans SC + Inter）

## 开发扩展

如需添加题目，在 `data/questions.js` 中按以下格式追加：

```js
{
  id: 'q999',
  subject: 'math',        // math | chinese | english
  chapter: 'math_02',     // 对应章节 ID
  type: 'choice',         // choice | fillblank | judge
  difficulty: 2,          // 1=简单 2=中等 3=较难
  isCommonMistake: true,  // 是否为高频易错题
  question: '题目文字',
  options: ['A. ...', 'B. ...', 'C. ...', 'D. ...'],
  answer: 'A',
  explanation: '详细解析...'
}
```
