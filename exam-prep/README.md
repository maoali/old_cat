# 深圳小学升初中 · 错题分析与训练系统

> 专为深圳六年级小学生升初中备考设计，完整覆盖小学阶段（1-6年级）数学、语文、英语全部核心考点。

---

## 快速开始

### 网页版（本地服务运行）

> **⚠️ 注意**：由于整合了多用户档案体系和模块化脚本，直接双击 `index.html` 可能会遇到浏览器本地跨域限制（CORS）导致部分功能加载失败。请务必通过本地 Web 服务运行。

环境要求：系统已安装 Python 3（Mac 通常自带）

```bash
# 1. 在项目根目录下启动本地服务器
python3 -m http.server 8080

# 2. 打开浏览器访问
http://localhost:8080
```

### Android App

> **前提**：已安装 [Android Studio](https://developer.android.com/studio)（含 JDK + Android SDK）

```bash
# 1. 安装 Node 依赖（首次）
npm install

# 2. 同步 Web 文件到 Android 工程
npm run sync

# 3. 用 Android Studio 打开工程
npm run open:android
# 然后在 Android Studio 中：Build → Build APK(s)
# APK 输出：android/app/build/outputs/apk/debug/app-debug.apk
```

| **百分数** | 百分数与分数/小数互化、百分数应用题、折扣、税率、利率 |

| **因数与倍数** | 因数、倍数、质数、合数、奇偶性、2/3/5的倍数特征、公因数、最大公因数、公倍数、最小公倍数 |

## 重点易错知识汇总

### 数学高频易错
- `4 ÷ 2/3 = 4 × 3/2 = 6`（除以分数=乘以倒数）
- 先涨20%再降20%：最终**少4%**
- 圆面积 `S = πr²`，周长 `C = 2πr`（r²≠r）
- 中位数 vs 平均数：{1,2,3,100}中位数=2.5，平均数=26.5
- 移项变号：`x-5=12` → `x=12+5=17`（不是12-5）
- 等底等高圆锥体积=圆柱体积×1/3

### 语文高频易错
- **多音字**：行（xíng/háng）、重（zhòng/chóng）、长（cháng/zhǎng）
- **成语误用**："差强人意"=勉强满意（非"很差"）
- **的地得**：的+名词，地+动词，动词+得
- **病句**："通过…使…"，删其一；"大约…左右"，删其一
- **古诗**：于谦（明）≠李白（唐），注意朝代！

### 英语高频易错
- `read`过去式也拼read，但读 `/red/`
- `an hour`（h不发音）；`a university`（/j/辅音开头）
- `homework/advice/information`：不可数，不加s/a
- 三单现在时动词+s/es：`She likes`（不是She like）
- 不规则复数：child→children，foot→feet，man→men

## 技术栈

### 网页版
- **纯前端**：HTML + Vanilla CSS + JavaScript，无需框架或构建工具
- **字体**：Google Fonts（Noto Sans SC + Inter）
- **数据持久化**：localStorage

### Android App
- **打包方案**：[Capacitor](https://capacitorjs.com/)（Web → 原生 Android WebView）
- **App 信息**：包名 `com.shenzhen.examprep`，最低 Android 5.0（API 21）
- **数据持久化**：同网页版（localStorage，关闭 App 后数据保留）
- **npm Scripts**：

  | 命令 | 说明 |
  |------|------|
  | `npm run sync` | 同步 `www/` 到 Android 工程 |
  | `npm run open:android` | 用 Android Studio 打开工程 |
  | `npm run build:apk` | 命令行构建 debug APK |
