# Eric's Blog

这是一个基于纯前端技术（HTML5, CSS3, JavaScript）构建的个人博客项目。该项目旨在提供一个干净、现代且响应式的个人网站，用于分享技术文章、生活随笔和思考。

## 🌟 特性 (Features)

*   **响应式设计**: 完美适配桌面端、平板和移动设备。
*   **深色模式支持**: 提供护眼的深色模式，并支持一键无缝切换。
*   **现代 UI 设计**: 采用流行的玻璃态、卡片式设计，搭配平滑的过渡动画，提供优质的用户体验。
*   **交互丰富**: 包含文章搜索弹窗、移动端侧边栏导航、回到顶部等实用交互功能。
*   **内容分类**: 支持按前端、后端、AI、DevOps等多种分类浏览文章。
*   **轻量级**: 纯静态页面，无需复杂的构建工具即可运行。

## 📁 目录结构 (Directory Structure)

*   `index.html`: 博客首页，包含个人简介、数据统计、精选文章和最新文章列表。
*   `articles.html`: 文章归档页，展示所有文章列表。
*   `article.html`: 文章详情页，用于阅读单篇文章的完整内容。
*   `categories.html`: 分类页，按不同标签或分类展示文章。
*   `about.html`: 关于页面，介绍博主信息及联系方式。
*   `css/`: 存放所有样式文件（如 `style.css`）。
*   `js/`: 存放所有交互逻辑的脚本文件（如 `main.js`）。

## 🚀 快速开始 (Getting Started)

由于本项目是纯静态网页，无需任何后端服务或构建工具即可在本地预览：

1. 克隆或下载本项目到本地。
2. 使用任何现代浏览器（Chrome, Firefox, Safari, Edge等）直接打开 `index.html` 文件。
3. （推荐）如果你有安装 VS Code，可以使用 Live Server 插件打开项目，以获得更好的开发和本地预览体验。

## 🛠️ 技术栈 (Tech Stack)

*   **HTML5** - 语义化页面结构
*   **Vanilla CSS3** - 自定义样式体系，支持 CSS 变量实现主题切换
*   **Vanilla JavaScript** - 实现页面动态交互逻辑
*   **Google Fonts** - 使用 Inter (英文字体) 和 Noto Sans SC (中文字体)
*   **Font Awesome** - 提供精美的矢量图标库
