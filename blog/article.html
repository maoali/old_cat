深入理解 JavaScript 异步编程

Eric 2026年2月1日 · 10 分钟阅读

目录

引言

JavaScript 是一门单线程语言，这意味着它一次只能处理一个任务。然而，在现代 Web 开发中，我们经常需要处理耗时的操作，如网络请求、文件读写等。异步编程就是解决这个问题的关键技术。

本文将带你深入了解 JavaScript 异步编程的演进历程，从回调函数到 Promise，再到 async/await，全面解析每种方式的优缺点和使用场景。

回调函数 (Callbacks)

回调函数是 JavaScript 中最早的异步处理方式。它的基本思想是：将一个函数作为参数传递给另一个函数，在异步操作完成后调用这个函数。

function fetchData(callback) {
    setTimeout(() => {
        const data = { name: 'Eric', age: 28 };
        callback(null, data);
    }, 1000);
}

fetchData((error, data) => {
    if (error) {
        console.error('Error:', error);
        return;
    }
    console.log('Data:', data);
});

虽然回调函数简单直接，但当我们需要处理多个连续的异步操作时，就会陷入所谓的"回调地狱"：

// 回调地狱示例
getUser(userId, (user) => {
    getOrders(user.id, (orders) => {
        getOrderDetails(orders[0].id, (details) => {
            // 嵌套越来越深...
            console.log(details);
        });
    });
});

Promise

Promise 是 ES6 引入的异步编程解决方案，它代表一个异步操作的最终完成（或失败）及其结果值。Promise 有三种状态：pending、fulfilled 和 rejected。

function fetchData() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const data = { name: 'Eric', age: 28 };
            resolve(data);
            // 如果出错：reject(new Error('Something went wrong'));
        }, 1000);
    });
}

fetchData()
    .then(data => console.log('Data:', data))
    .catch(error => console.error('Error:', error));

Promise 最大的优势是可以通过链式调用来处理多个异步操作，避免回调地狱：

getUser(userId)
    .then(user => getOrders(user.id))
    .then(orders => getOrderDetails(orders[0].id))
    .then(details => console.log(details))
    .catch(error => console.error(error));

Async/Await

Async/await 是 ES2017 引入的语法糖，让异步代码看起来像同步代码一样直观。async 函数返回一个 Promise，await 关键字会暂停函数执行，直到 Promise 完成。

async function fetchUserData(userId) {
    try {
        const user = await getUser(userId);
        const orders = await getOrders(user.id);
        const details = await getOrderDetails(orders[0].id);
        console.log(details);
    } catch (error) {
        console.error('Error:', error);
    }
}

fetchUserData(123);

如果需要并行执行多个异步操作，可以使用 Promise.all：

async function fetchAllData() {
    const [users, products, orders] = await Promise.all([
        fetchUsers(),
        fetchProducts(),
        fetchOrders()
    ]);
    return { users, products, orders };
}

最佳实践

💡 异步编程最佳实践

  • 优先使用 async/await，代码更清晰易读
  • 始终处理错误，使用 try/catch 或 .catch()
  • 合理使用 Promise.all 并行化独立的异步操作
  • 避免在循环中使用 await，考虑使用 Promise.all
  • 使用 AbortController 处理可取消的请求

总结

JavaScript 异步编程经历了从回调函数到 Promise，再到 async/await 的演进。每种方式都有其适用场景：

  • 回调函数：简单场景，但容易导致回调地狱
  • Promise：链式调用，更好的错误处理
  • Async/Await：最直观的语法，推荐使用
