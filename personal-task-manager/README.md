# 个人事务管理程序

一个简洁高效的个人事务管理和提醒工具，支持本地运行，无需服务器。

## 功能特点

- ✅ **事务管理**：添加、编辑、删除个人事务
- ⏰ **智能提醒**：支持时间提醒，包括浏览器通知和应用内弹窗
- 🎯 **优先级设置**：高、中、低三个优先级别，用颜色区分
- 📊 **状态筛选**：查看全部、待处理、已完成事务
- 💾 **本地存储**：数据保存在浏览器本地存储中，刷新不丢失
- 🎨 **简洁界面**：现代化设计，响应式布局，支持移动端
- 🔄 **实时更新**：自动检查提醒，及时通知

## 使用方法

### 1. 打开应用

直接在浏览器中打开 `index.html` 文件即可使用。

### 2. 添加事务

1. 在"添加新事务"区域填写信息：
   - **事务标题**（必填）：输入要处理的事务名称
   - **描述**（可选）：添加详细说明
   - **日期**（必填）：选择事务日期
   - **时间**（必填）：设置具体时间
   - **优先级**：选择高、中、低优先级

2. 点击"添加事务"按钮

### 3. 管理事务

- **完成事务**：点击事务卡片上的"完成"按钮
- **删除事务**：点击"删除"按钮（需要确认）
- **筛选查看**：使用顶部的筛选按钮查看不同状态的事务

### 4. 提醒功能

- 应用会自动检查即将到来或已过期的事务
- 支持浏览器通知（需要授权）
- 支持应用内弹窗提醒
- 在事务时间前5分钟和到达时间时都会提醒

## 技术特点

- 纯前端实现，无需后端服务器
- 使用 localStorage 进行数据持久化
- 响应式设计，支持各种屏幕尺寸
- 现代化的渐变色设计
- 流畅的动画效果

- Firefox

## 数据安全

- 所有数据存储在本地浏览器中
- 不会上传到任何服务器
- 清除浏览器数据会丢失所有事务

## 高级功能

### 清理过期事务

在浏览器控制台中执行以下代码可以清理一周前已完成的旧事务：

```javascript
taskManager.cleanupOldTasks();
```

### 导出数据

在控制台中执行以下代码可以导出所有事务数据：

```javascript
console.log(JSON.stringify(taskManager.tasks, null, 2));
```

## 注意事项

1. 首次使用时，浏览器会请求通知权限，建议允许以获得完整的提醒体验
2. 建议定期备份重要数据
3. 如果更换浏览器或清除缓存，数据会丢失
